# Route identity preservation

This fork assigns stable names to 23 known pairs of route endpoints generated by the original mod and Redrawn Space Connections. It reuses each existing route prototype and changes only its name. Length, endpoint order, geometry and asteroid definitions remain those selected by the current mod combination. No duplicate physical route is added.

Native JSON migrations retain saved references to renamed route prototypes. Because the platform distance API is measured from the prototype's `from` endpoint, an upgrade that reverses endpoints must also mirror an in-flight platform's distance while retaining its forward speed. This adjustment retains its physical position and travel direction, inventory, fuel, schedule and pause state. Original IRF spokes and Redrawn-generated names are distinguished using the previous mod set. The current endpoint orientation is saved at initialization and after configuration changes so later rebuilds do not repeat a completed adjustment.

Factorio 2.1.24 native fixtures covered both travel directions, active and paused zero-speed trips, ordinary renamed routes, unchanged names with reversed endpoints, original IRF spokes, saved prototype references and configuration reloads.
