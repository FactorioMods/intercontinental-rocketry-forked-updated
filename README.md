# Intercontinental Rocketry Forked: Updated

Creates additional copies of supported planets so another surface of the same planet type can be explored and developed. Startup settings select the number of copies for each supported planet.

This continuation supports Factorio 2.1, retains original planet and setting identities, recognizes the maintained Metal and Stars namespace, and makes Redrawn Space Connections optional. Stable route identities and native ownership migration retain existing worlds when upgrading from the original mod.

Version 1.0.1 keeps copied planets beside their parents with native parent-relative orbit coordinates. It preserves PlanetsLib's child orbit when refreshing copied surface definitions; space connection lengths, planet generation, and gameplay values remain unchanged.

Verified with Factorio 2.1.24 and PlanetsLib 2.5.2: copied-planet positions, saved surfaces, platform inventories and schedules, route identities and lengths, save/reload, and multiplayer join/rejoin with a real client. Native prototype comparison confirmed that only the copied planets' orbit fields change.

Requires Factorio 2.1.24 or newer, Space Age, and PlanetsLib. Planet coverage is explicit; installing another planet mod does not automatically guarantee copied planets for it.
