# Intercontinental Rocketry Forked: Updated

Creates additional copies of supported planets so another surface of the same planet type can be explored and developed. Startup settings select the number of copies for each supported planet.

This continuation updates planet and route definitions for Factorio 2.1, retains original planet and setting identities, recognizes the maintained Metal and Stars namespace, and makes Redrawn Space Connections optional.

Requires Factorio 2.1.24 or newer. Requires Space Age and PlanetsLib. Planet coverage is explicit; installing another planet mod does not automatically guarantee copied planets for it.
